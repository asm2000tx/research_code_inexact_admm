#### Research Code - Inexact ADMM with Relative Error Criterion

This repository consists of code of the inexact ADMM with relative error criterion. The algorithms for this repo is based on the following papers: 

1. _An inexact alternating direction method of multipliers with relative error criteria_ 
    * Jiaxin Xie,
    * Anping Liao, 
    * Xiaobo Yang.

2. _On inexact ADMMs with relative error criteria_ 
    * Jiaxin Xie.

To access the code to these papers, enter `cd ../iadmm_<<authors>>` where `<<authors>>` is replaced with one of the following:
1. `jax` - Jiaxin Xie, Anping Liao, and Xiaobo Yang,
2. `xie` - Jiaxin Xie.

Once in the respective file, enter `python3 main.py` in the terminal to exectue the algorithm.
